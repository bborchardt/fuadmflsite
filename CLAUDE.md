# The analysis branch

This branch (`claude/fantasy-football-tier0-setup`) holds planning only: `docs/roadmap.md` (what's
next and the commissioner's to-dos) and the skin preview tool. It is never merged. Code work
branches from master, whose `AGENTS.md` has the working notes and whose `docs/` has the design and
MFL facts; read those first. Update the roadmap here when plans change.

Fixed · deployed 3 Oct 2026

Shipped in PR #1, verified on the live page

  1. 01

    The injured-starter warning works Fixed

    Injuries now load from MFL's api host: 464 records, 347 players flagged, 55 of them rostered. IR-R, IR-PUP and IR-NFI count as injured too. No Week 3 starter was injured, so "No violations found" is now a real result.

    Was: the request went to the wrong host, got an error, and flagged nobody.
  2. 02

    Rookie salaries use the league's fixed baselines Superseded

    QB $6, RB $10, WR $10, TE $4, PK $1 for the first pick, each later pick still 80% of the one before. The table runs from those values at pick 1 to $1 across the board at pick 15.

    Was: kicker salaries showed $NaN, because the baseline was the 15th-highest kicker salary and only 14 were rostered.
  3. 03

    The Contracts tab stacks on phones Fixed

    Below MFL's 62.5em breakpoint the two columns go full width, with the calculator and salary tables first. No table overflows. Desktop is unchanged.

    Was: the sidebar was crushed into 134px and its text overlapped.
  4. 11

    The repo matches production Fixed

    All five files in src/ match the live page line for line.

    Was: the repo still had 2022 season values, and production had a stray debug line.
Background

No action owed

  1. 12

    MFL's platform rules are unchanged, so the Tier 2 plan stands Unchanged

    Cross-origin reads are still blocked and the page still sends no CSP. The API terms still forbid off-site JavaScript and exempt in-page calls from rate limits. A thin loader in MFL with the app on GitHub Pages is still the recommendation.

  2. 13

    Data loading is slow in shape, not in size

    Eight requests run one after another, taking 0.75s on home broadband. In parallel it would be about 0.25s. Worth fixing in a rewrite, not urgent on its own.

  3. 14

    No JavaScript errors on any tab

    Checked again after the fixes deployed. The four 2012-era libraries still load from cdnjs and still work.

  4. —

    The Contracts tab is still long on a phone

    15,226px, about 18 screens, because it lists every rostered player in the league. That needs a "My Team" view, which is a content change rather than a bug fix.

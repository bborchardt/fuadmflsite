The work, in order

Six changes, in detail

1
csetup?L=48571&C=HMPGMOD — Home Page Modules and Tabs Setup

Move or remove Power Rankings

Sixteen columns: Franchise, W-L-T, PF, PP, Eff, Bench Points, Max PF, Min PF, Coulda Won, Woulda Lost, Power Rank, Alternate Power Rank, W, L, T, Pct. With real stats in it, it now runs 588 px into a 390 px screen. It was 514 px preseason. The right third is gone on a phone.

  1. Move it to its own tab, where a wide page is expected.
  2. Drop it. MFL's menu already links Power Rank (options?L=48571&O=101).
  3. Keep it and accept the clipping, only if the league actively uses it.

League Standings also clips, by 25 px (the Avg PA column). It is MFL's module, so leave it unless step 2 removes the tab anyway.

2
csetup?L=48571&C=HMPGMOD — Home Page Modules and Tabs Setup

Drop the two duplicate tabs

MFL's own navigation row already carries Standings and Live Scoring, and so does our custom row. On a phone both rows collapse into separate hamburger menus, so a member can open the wrong one first.

Drop the custom Standings and Live Scoring tabs. The Live Scoring tab holds a single score summary, and MFL's own page (ajax_ls?L=48571) is the real thing. Dropping Standings also resolves step 1.

Check first: open MFL's native Standings page on a phone. If it reads worse than the custom tab, keep the tab and just do step 1.

3
csetup?L=48571&C=HMPGMOD — Home Page Modules and Tabs Setup

Rename the Transactions tab

The August runbook said this tab duplicated MFL's Transactions page. It doesn't. It holds Trade Bait, Top 10 Free Agents and the Starter Points chart, and the league's transactions list is on Main. The tab is only misnamed. Rename it to something like Players or Free Agents, and keep it.

4
csetup?L=48571&C=HMPGMOD — Home Page Modules and Tabs Setup

Remove the unused modules

In August these were empty because it was preseason, and the advice was to wait. Four weeks in, League Chat, League Poll and Trade Bait are all still empty. Over the same period the message board has seven topics since 6 Sep, so the league has a place to talk and doesn't use these. Removing Chat and Poll shortens Main on a phone.

5
csetup?L=48571&C=SKIN — Select A Skin

Reconsider the skin, for legibility only

Still BlueMesh: dark navy, blue headers. It isn't broken. A light skin reads better on a phone outdoors. The skin doesn't change layout: Power Rankings measured 514, 525 and 514 px under BlueMesh, AllAmerican and AquaGreen in August. Preview against the real page with cd tools/skin-preview && node preview.js AllAmerican AquaGreen.

6
Post one league message

Point members at a phone app

All three are still listed on the App Store as of 3 Oct: MFL Modern (newest, free for one team, uses existing MFL logins), MFL Mobile and MFL Platinum. They handle rosters, lineups and live scoring well. They don't render custom home page modules, so app users won't see the Contracts tab at all. That's why Tier 0 can't be the whole answer.

Scope

What Tier 0 will not fix

  • The length of the Contracts tab: 13,800 px of roster on a phone. Needs a "My Team" view.
  • The eight sequential data requests.
  • The annual code edits for year, beforeDraft and the post-deadline block. The post-deadline one is due this season.

The injured-starter warning and the kicker $NaN were code bugs outside Tier 0. Both were fixed in PR #1.

Before you start

The checklist

  • Check MFL's native Standings page on a phone
  • Drop the custom Standings and Live Scoring tabs, or move Power Rankings
  • Rename the Transactions tab
  • Remove League Chat, Poll and Trade Bait
  • Preview two or three skins; switch or keep deliberately
  • Post one league message recommending a phone app

Method

How these numbers were produced

3 Oct. The live page was loaded directly in Chrome via Playwright, at 390×844 and 1440×900, logged out. Because it ran on MFL's own origin, our scripts ran too. Each tab was shown with MFL's own show_tab(), and every table whose right edge passed the viewport was recorded. The Contracts CSS was tested by injecting it into the same page, then re-checked on the live page after PR #1 was deployed.

What the August method got wrong

tools/skin-preview mirrors the page locally and swaps the skin stylesheet. It strips scripts, so it can't see anything our code draws. That caused two wrong conclusions in the first runbook: it placed the Cap Penalty Calculator on Main (it is on Contracts), and it assumed the contract table overflowed sideways (it squeezes; the sidebar was what broke). Use the tool to compare skins, not to judge our own tabs.

Captured logged out, so the Commish tab and franchise-specific views were not seen as a member or commissioner would see them.

One tab is the problem, and the thing making it a problem is an MFL module the commissioner can move or remove. That turns the headline mobile complaint into a Tier 0 fix rather than a code project.

Already done

Don't spend time here

The options review listed "check the mobile setting" as step one. It's done — the page already serves <meta name="viewport" content="initial-scale=1.0, width=device-width"> and loads skins17/BlueMesh/responsive.css. At 390 px the menu and tab bar collapse to hamburgers and the two home-page columns stack to full width. MFL's own CSS is doing its job.

The easy win is already collected — which is also why what's left is more specific.

The work, in order

Five changes, all in admin

1
For Commissioners → Setup → Home Page Modules and Tabs

Remove or relocate Power Rankings

This is the one real mobile fix in Tier 0. The module carries sixteen columns — Franchise, W-L-T, PF, PP, EFF, Bench Points, Max PF, Min PF, Coulda Won, Woulda Lost, Power Rank, Alternate Power Rank, W, L, T, PCT. At 390 px the last four are simply off-screen with no scroll affordance, so members don't know they're missing anything.

  1. Move it to its own tab — keeps Standings readable, and anyone wanting the deep numbers opens a page that's expected to be wide.
  2. Drop it — nothing links to it and the same information is in MFL's own reports.
  3. Keep and accept the clipping — only if the league actively uses it.

Re-measure afterwards with MFL_TAB=1 node preview.js.

2
For Commissioners → Setup → Home Page Modules and Tabs

Fix the duplicated navigation

The page shows two rows of navigation. MFL's own row carries Home, Rosters, Draft, Submit Lineup, Add/Drops, Trades, Player Stats, Standings, Transactions, Live Scoring and Schedule. Our custom row carries Main, Standings, Transactions, Contracts, Calendar, Commish, Links and Live Scoring.

Three of our eight tabs duplicate a destination MFL already provides one row above. On a phone both rows collapse into separate hamburgers, so a member opens one, doesn't find what they want, and opens the other.

Proposal: drop the custom Standings, Transactions and Live Scoring tabs and let MFL's native pages own those jobs. That leaves five — Main, Contracts, Calendar, Commish, Links — of which Contracts is the one that genuinely justifies a custom tab. It also resolves step 1 for free, since Power Rankings lives on the custom Standings tab.

Confirm first: open MFL's native Standings page on a phone and check it reads better than the custom tab. If it doesn't, keep the tab and just do step 1.

3
Edit the home page message that renders it

Move the Cap Penalty Calculator off the Main tab

It sits in the right column of the Main tab today. It's one of ours, it's genuinely useful, and it is not something a member needs on first paint — it answers "what would it cost to cut this guy", which is a question you go looking for.

The principle from the options review was common functions obvious, advanced functions possible. This is an advanced function in the most prominent slot on the site. Move it to the Contracts tab, beside the data it operates on.

4
For Commissioners → Setup → Appearance Setup → Select a Skin

Reconsider the skin — for legibility, not layout

The league is on BlueMesh from MFL's 2017 set: dark navy ground, blue headers, white text. It is neither broken nor ugly. Its weaknesses on a phone are daylight contrast and fairly dense table rows.

A light skin is markedly easier to read on a phone outdoors. But note the last column: the skin does not affect the overflow at all. Choose for legibility and expect nothing else to change.

Preview any skin against the real page before committing — MFL's picker only shows a generic thumbnail:

cd tools/skin-preview && node preview.js AllAmerican AquaGreen

The full skin list is only visible inside Appearance Setup — the names aren't discoverable from outside — so take them from that screen and pass them in with spaces removed: "All American" becomes AllAmerican.

5
Post one league message before Week 1

Point the league at a phone app for lineups

All three are still published: MFL Modern (newest, free for one team, logs in with existing MFL credentials), MFL Mobile and MFL Platinum. Rosters, lineups and live scoring are the most common member jobs and are entirely MFL-native, so an app does them well with no work from us.

The limit to be honest about: apps generally don't render custom home page modules, so members living in an app won't see the Contracts tab at all. That's the argument for not letting Tier 0 be the whole answer.

Scope

What Tier 0 will not fix

Worth being clear so expectations match the work.

  • The contract tables — seven columns, drawn by our code. Untouched by any setting or skin. That's Tier 1/2.
  • The injuries bug — a one-line code fix, unrelated to any of this, and worth doing on its own.
  • The eight sequential data requests behind the Contracts tab.
  • The annual code edits for year, beforeDraft and the post-deadline block.
Before you start

The checklist

  • Decide Power Rankings: own tab, remove, or keep
  • Check MFL's native Standings on a phone, then drop the duplicate custom tabs
  • Move the Cap Penalty Calculator to the Contracts tab
  • Preview two or three skins against the real page; switch or keep deliberately
  • Post one league message recommending a phone app
  • Re-run MFL_TAB=all node preview.js and confirm no tab overflows
Method

How these numbers were produced

Figures come from tools/skin-preview, which mirrors the live home page, swaps in a skin's stylesheets, and screenshots at 390×844 and 1440×900, flagging any table wider than the viewport.

One correction worth recording

An early version of the harness stripped every script, including the inline show_tab(0) call that hides all tabs but the first. That made the page render all eight tabs stacked and report ~4,050px on a phone — which looked like a damning result and was entirely an artifact of the measurement.

The tool now re-implements the tab initialisation, and the real figure is 1,036px. Every number on this page is from the corrected version. It's a reminder that a harness that strips the page's behaviour will happily invent a problem to solve.

Everything was captured logged out, so member-only and commissioner-only views may differ. The harness cannot render tabs whose content our own JavaScript draws — Contracts, Commish and Links — so those are excluded from the table above rather than reported as small.
